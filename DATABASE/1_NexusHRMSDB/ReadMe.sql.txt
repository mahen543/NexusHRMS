# NexusHRMSDB Database

Microsoft SQL Server database used by the NexusHRMS
ASP.NET Core Web API.

## Structure

| Folder 		==> Purpose |

| 01_Database 		==> Database creation scripts |
| 02_Tables 		==> Table definitions |
| 03_SeedData 		==> Initial/sample data |
| 04_StoredProcedures 	==> Stored procedures |
| 05_Indexes 		==> Database indexes |
